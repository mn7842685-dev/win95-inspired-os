# Win95-Inspired Operating System

## Project Goal

Build a small educational operating system from scratch,
inspired by the classic desktop computing experience.

## Main Components

1. CPU
2. Bootloader
3. Kernel
4. Memory Management
5. Keyboard Input
6. Display Output
7. File System
8. Graphical User Interface
9. Basic Applications

## Development Approach

The project will be developed step by step,
with each major component tested separately
before integration.
